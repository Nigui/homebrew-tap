# Nigui/homebrew-tap

Homebrew tap for [Tackit](https://github.com/Nigui/tackit) — blazing-fast, keyboard-driven sticky notes for macOS.

## Install

```sh
brew install --cask nigui/tap/tackit
```

> The current build is a **pre-release and not yet notarized**, so add
> `--no-quarantine` (or right-click → Open the first time):
>
> ```sh
> brew install --cask --no-quarantine nigui/tap/tackit
> ```

## Update / uninstall

```sh
brew upgrade --cask tackit
brew uninstall --cask tackit
```
